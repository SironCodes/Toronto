# Toronto.ca audit and redesign concept

An outside-in audit of [toronto.ca](https://www.toronto.ca) using only public information, plus a redesign concept for the site.

## Contents

- `toronto_ca_audit.md`: the audit (security, privacy, performance, accessibility, tech debt), with ranked findings.
- `toronto_ca_content_inventory.csv`: every sitemap URL with section, template guess, depth and last-modified date. Sampled rows add status, title, H1 and word count.
- `toronto_redesign.html`: the current redesign concept. Open it in a browser.
- `toronto_redesign_v1.html`: the earlier version.
- `assets/`: images used by the redesign.

## Notes

This is an independent concept. It is not affiliated with or endorsed by the City of Toronto.
